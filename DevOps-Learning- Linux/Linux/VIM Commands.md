# 📝 VI / VIM Basic Commands

|Command|Description|
|---|---|
|`i`|Enter **Insert mode**|
|`Esc`|Exit Insert mode → Normal mode|
|`:wq`|**Write (save) and quit**|
|`:q`|Quit the file|
|`:q!`|Force quit **without saving**|
|`gg`|Move to the **first line** of the document|
|`G`|Move to the **last line** of the document|
|`u`|Undo the last action|
|`Ctrl + r`|Redo the undone action|
|`yy`|Copy the **current line**|
|`5yy`|Copy **5 lines**|
|`2yy`|Copy **2 lines**|
|`p`|Paste copied text **after** the cursor|
|`P`|Paste copied text **before** the cursor|
|`dd`|Delete the current line|
|`5dd`|Delete **5 lines**|
|`/search`|Search for a word/text|
|`n`|Go to the **next search result**|
|`N`|Go to the **previous search result**|
|`:10`|Go to the **10th line**|

---
